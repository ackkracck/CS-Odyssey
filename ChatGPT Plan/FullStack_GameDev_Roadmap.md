# 🎯 2-Year Roadmap: Full-Stack Developer + Game Developer

This roadmap balances **financial stability (Full-Stack Development)**
with **creative passion (Game Development)**.\
By following it, you'll become employable as a developer within 12
months and publish at least one game within 24 months.

------------------------------------------------------------------------

## 📅 Year 1: Become a Job-Ready Full-Stack Developer

**Main Goal**: Build professional full-stack skills to land a job or
freelance income.

### 🔹 Months 1--3: Strengthen Fundamentals

-   [ ] Learn **HTML5** & **CSS3** (responsive design, flex/grid,
    accessibility)
-   [ ] Master **JavaScript (ES6+)**: DOM, fetch API, promises,
    async/await
-   [ ] Build and host a **personal portfolio website**

📌 **Project**: Portfolio site (GitHub Pages / Netlify)

------------------------------------------------------------------------

### 🔹 Months 4--6: React + TypeScript

-   [ ] Learn **React** (components, props, state, hooks)
-   [ ] Learn **TypeScript** (types, interfaces, generics)
-   [ ] Explore React Router & Context API

📌 **Project**: Small app (Task Manager, Recipe Tracker)

------------------------------------------------------------------------

### 🔹 Months 7--9: Backend & Databases

-   [ ] Learn **Node.js + Express** (REST APIs, JWT auth)
-   [ ] Learn **PostgreSQL** (schemas, joins, transactions)
-   [ ] Learn ORM (Prisma / Sequelize)

📌 **Project**: Full-stack CRUD app (Blogging platform with accounts,
comments, likes)

------------------------------------------------------------------------

### 🔹 Months 10--12: Deployment & Career Prep

-   [ ] Learn **Docker** basics & CI/CD pipelines (GitHub Actions)
-   [ ] Deploy apps (Vercel, Railway, AWS Lightsail)
-   [ ] Practice interviews: Algorithms (LeetCode Easy/Medium), System
    Design basics

📌 **Capstone Project**: SaaS clone (Trello board, Expense Tracker, or
Mini Social Network)

✅ **Year 1 Outcome**:\
- Job-ready full-stack developer (junior/intermediate)\
- 3--4 polished projects in portfolio\
- Able to freelance or apply for dev roles

------------------------------------------------------------------------

## 📅 Year 2: Dual-Track (Full-Stack Career + Game Development Side)

**Main Goal**: Earn from full-stack skills while developing and
publishing your first games.

### 🔹 Months 13--15: Professionalizing Full-Stack

-   [ ] Land freelance gigs or developer role\
-   [ ] Learn testing (Jest), advanced Git, APIs, GraphQL\
-   [ ] Start small SaaS/freelance side-income project

📌 **Project**: Paid freelance app or niche SaaS tool

------------------------------------------------------------------------

### 🔹 Months 16--18: Game Development Foundations

-   [ ] Pick engine (**Godot** recommended)\
-   [ ] Learn 2D basics: sprites, tilemaps, collisions, input\
-   [ ] Write simple scripts (GDScript / C#)

📌 **Project**: Prototype game (Flappy Bird clone or Farming Mini-Game)

------------------------------------------------------------------------

### 🔹 Months 19--21: First Publishable Game

-   [ ] Add saving/loading, menus, music, polish\
-   [ ] Playtest with friends & gather feedback\
-   [ ] Publish game on **itch.io or Steam**

📌 **Project**: Cozy Game (Exploration, Farming, or Story-driven)

------------------------------------------------------------------------

### 🔹 Months 22--24: Scaling Both Paths

-   [ ] Advance full-stack skills (system design, caching, scaling)\
-   [ ] Add features/updates to game post-launch\
-   [ ] Explore multiplayer (Godot networking or Photon)\
-   [ ] Combine skills: Build **game + web integration** (leaderboards,
    profiles)

📌 **Project**: Game with online leaderboard using your full-stack
backend

✅ **Year 2 Outcome**:\
- Stable income stream (job or freelancing)\
- 1--2 games publicly released\
- Strong foundation to either grow dev career OR pivot into games

------------------------------------------------------------------------

## 🚀 Long-Term Strategy

-   **Plan A (Safe)**: Grow as a full-stack developer → steady 6-figure
    income in Australia.\
-   **Plan B (Passion)**: Build small games until one takes off → scale
    into indie studio/side income.\
-   **Plan C (Hybrid)**: Use full-stack to build **game tools, SaaS for
    developers, or multiplayer backends**.
